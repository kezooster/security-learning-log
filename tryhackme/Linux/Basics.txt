1. pwd - your location
2. cat - read a file
3. cd - move through the directories 
4. find - finds file with specified name 
  we can find files by:
    1) Names:
      '-name "*.txt"' - is case sensitive 
      '-iname"README.md"' - ignores case
    2) Size: 
      '-size 124c' 
      suffixes: c(bytes), k(KB), m(MB), g(GB)
    3) Type:
      '-type f' also support -b (block), -d (directorie), -l (symbolic link), -c (character)
    4) Permision:
      '-perm 644' (4 writing, 2 reading, 1 execute)
    5) Ownership:
      '-user Ed' or '-group developers'
    6) Time:
      '-mtime -7' - modiffied in last 7 days ago
      '-atime +30' - accessed over 30 days ago
      '-ctime 1' - status changed exactly 24–48h ago
  P.S. if you will type / after find search will be started from the root 
5. grep "password" passwords.txt - finds text inside a file
6. ls - helps to look up what is inside current folder
options for ls:
1) -a shows all hidden files
P.S. You can wright 'ls --help' and it will show all posible options and instructions while MAN(ual) 'man ls' gives description of what command dose
7. touch "name.txt" - creates file
8. mkdir "folder_name" - creates folder
9. rm "file.txt" - removes file
10. cp 'file_name" "path" - copies the file where you want 
options for rm:
1) you can use -R option to delte recursively that means the entire tree will be deleted 
operators:
1) & - runs a command in a back ground while you can run other commands 
2) && - runs bot commands one by one like a domino 
3) > - 	Used to redirect output. We can take the output of a command and send it to a file. This operator will overwrite anything that exists in the file.
4) >> - This redirector does the same thing, but instead of overwriting, it will just add the output to the bottom of the file.
11. ps - command that shows you which processes running currently 
12. ps aux - do the same as ps but it shows processes for all users 
13. kill - kills process command should look like: "kill'PID'"
  singals for the processes that we can send when it’s killed:
    1)SIGTERM - Kill the process, but allow it to do some cleanup tasks beforehand
    2)SIGKILL - Kill the process - doesn't do any cleanup after the fact
    3)SIGSTOP - Stop/suspend a process
14. systemctl - command that helps us interact with systemd process it should look like: "systemctl [options] [process]"
  options: 
    1)start
    2)stop 
    3)enable 
    4)disable 
    5)status
15. top - shows your processes in realtime
16. wget - download smth from a wweb site for example: "wget https://assets.tryhackme.com/additional/linux-fundamentals/part3/myfile.txt"
  also we can run a python server and download smth from there example:
    1)"python3 -m http.server" 
    2)"wget http://[MACHINE-IP]:8000/[filename]"
17. scp - allows you to copy files from others computer by ssh connection and download files to connected pc 
  commands: 
    1)for copying files to remote pc: scp [filename] [username@ip]:[file-path]
    2)for copying files from remote pc: scp [username@ip:] [file-path] [copied-file-name] 
18. crontab - helps us boot smth after pc just started its work (in the processes look like cron)
  specific values for cron:
    1)MIN - what minute to execute at 
    2)HOUR - what hour to execute at 
    3)DOW - what day of the week to execute at 
    4)DOM - what day of the month to execute at 
    5)MOY - what month of the year to execute at
    6)CMD - actual command to execute 
  example:
    "crontab 0 12 * * * echo "Its 12AM Good Morning!"
  P.S. you can use '*' symbol if you dont care about option and also you can open crontab editor by using command crontab -e 
19. ifconfig/ ip a s - shows you ip address
