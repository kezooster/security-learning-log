10. cp 'file_name" "path" - copies the file where you want 
options for rm:
1) you can use -R option to delte recursively that means the entire tree will be deleted 
operators:
1) & - runs a command in a back ground while you can run other commands 
2) && - runs bot commands one by one like a domino 
3) > - 	Used to redirect output. We can take the output of a command and send it to a file. This operator will overwrite anything that exists in the file.
4) >> - This redirector does the same thing, but instead of overwriting, it will just add the output to the bottom of the file.
